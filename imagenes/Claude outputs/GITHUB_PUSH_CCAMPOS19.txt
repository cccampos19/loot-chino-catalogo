═══════════════════════════════════════════════════════════════════
    ✅ PASO 5: EJECUTAR LOS COMANDOS DE GIT
───────────────────────────────────────────────────────────────────

Copia y pega EXACTAMENTE ESTOS COMANDOS (uno por uno):


COMANDO 1 - Inicializar Git:
───────────────────────────
git init

Presiona Enter. Espera a que termine.


COMANDO 2 - Configurar tu nombre y email (una sola vez):
───────────────────────────────────────────────────────
git config --global user.name "Carlos Campos"
git config --global user.email "tu.email@gmail.com"

(Reemplaza "tu.email@gmail.com" con tu email real)

Presiona Enter.


COMANDO 3 - Agregar todos los archivos:
───────────────────────────────────────
git add .

Presiona Enter.


COMANDO 4 - Crear el primer commit:
───────────────────────────────────
git commit -m "Initial commit: Catálogo Loot Chino con 13 productos"

Presiona Enter.


COMANDO 5 - Cambiar el nombre de la rama a "main":
───────────────────────────────────────────────────
git branch -M main

Presiona Enter.


COMANDO 6 - Conectar con tu repositorio de GitHub:
───────────────────────────────────────────────────
git remote add origin https://github.com/CCAMPOS19/loot-chino-catalogo.git

Presiona Enter.


COMANDO 7 - SUBIR TODO A GITHUB (el más importante):
────────────────────────────────────────────────────
git push -u origin main

Presiona Enter.

    ❓ SOLUCIÓN DE PROBLEMAS COMUNES
───────────────────────────────────────────────────────────────────

❌ "git: command not found"
   → Git no está instalado. Descarga de: https://git-scm.com/download/win

❌ "fatal: invalid username"
   → Tu usuario GitHub es CCAMPOS19 (sin espacios ni caracteres especiales)

❌ "fatal: Authentication failed"
   → Necesitas un token. Ve a: https://github.com/settings/tokens

❌ "The remote repository does not exist"
   → Asegúrate de que el repositorio existe en GitHub
   → La URL debe ser: https://github.com/CCAMPOS19/loot-chino-catalogo.git

❌ "error: pathspec 'Loot cino' did not match any files"
   → El error es por el espacio en el nombre. Usa: cd "Downloads\Loot cino"
   → Con comillas!
