═══════════════════════════════════════════════════════════════════
    PASO 1: CREAR LA CARPETA (1 MINUTO)
═══════════════════════════════════════════════════════════════════

1. Abre Command Prompt (Windows) o Terminal (Mac)

2. Navega a tu carpeta de descargas:
   cd Downloads

3. Crea la estructura:
   mkdir catalogo-loot-chino-github
   cd catalogo-loot-chino-github
   mkdir imagenes


═══════════════════════════════════════════════════════════════════
    PASO 2: COPIAR ARCHIVOS (2 MINUTOS)
═══════════════════════════════════════════════════════════════════

1. El HTML que descargaste: renómbralo a "index.html" y colócalo aquí:
   📍 catalogo-loot-chino-github/index.html

2. Tus imágenes de "Loot cino\imagenes" cópialas a:
   📍 catalogo-loot-chino-github/imagenes/

3. Descarga estos 4 archivos desde Claude y colócalos en la raíz:
   - README.md
   - vercel.json
   - .gitignore
   - GITHUB_DEPLOYMENT.md

   (Los puedes descargar desde este chat)


═══════════════════════════════════════════════════════════════════
    PASO 3: INICIALIZAR GIT (1 MINUTO)
═══════════════════════════════════════════════════════════════════

En Command Prompt, dentro de la carpeta:

git init
git add .
git commit -m "Initial commit: Catálogo Loot Chino"


═══════════════════════════════════════════════════════════════════
    PASO 4: CREAR REPO EN GITHUB (1 MINUTO)
═══════════════════════════════════════════════════════════════════

1. Ve a github.com
2. Click "+" (arriba a la derecha) → "New repository"
3. Llena:
   - Name: loot-chino-catalogo
   - Description: Catálogo de productos chinos
   - Public: ✅ Sí
   - Click "Create repository"

4. Copia la URL que te muestra (algo como):
   https://github.com/TU_USUARIO/loot-chino-catalogo.git


═══════════════════════════════════════════════════════════════════
    PASO 5: SUBIR A GITHUB (1 MINUTO)
═══════════════════════════════════════════════════════════════════

En Command Prompt:

git branch -M main
git remote add origin https://github.com/TU_USUARIO/loot-chino-catalogo.git
git push -u origin main

(Reemplaza "TU_USUARIO" con tu usuario de GitHub)


═══════════════════════════════════════════════════════════════════
    LISTO! 🎉
═══════════════════════════════════════════════════════════════════

Tu código está en GitHub. Ahora en Vercel:

1. Ve a vercel.com
2. Click "New Project"
3. Importa tu repositorio de GitHub
4. Click "Deploy"
5. En 2 minutos tendrás tu catálogo en vivo:

   🌐 https://loot-chino-catalogo.vercel.app

   ¡Las imágenes y el botón de WhatsApp ya están funcionando!

¿PROBLEMAS?

❌ "git: command not found"
   → Instala Git: https://git-scm.com/download

❌ Las imágenes no aparecen
   → Verifica que la carpeta sea exactamente "imagenes/"
   → Los nombres de archivos sean idénticos (mayúsculas/minúsculas)

❌ "fatal: could not read Username"
   → En Windows: git config --global credential.helper manager
